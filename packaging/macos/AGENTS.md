# Dots Voice 설치 작업 지침 (macOS)

이 폴더는 Chrome dots 통화의 답변 음성을 포함된 **로컬 목소리**로 바꾸는 로컬 도구의 설치 패키지다. 사용자가 설치·연결·진단을 맡기면 이 파일과 `SETUP.md`를 따른다. 원본 사용자의 경로가 아니라 **현재 패키지 폴더**를 기준으로 작업한다.

## 시작 전

- 사용자 컴퓨터에서 명령을 실행할 수 없는 환경(웹 채팅 등)이면 설치했다고 하지 않는다. `README.md`의 **직접 설치** 절차를 사용자에게 안내한다.
- ZIP 상태로 받았다면 계속 보관할 위치에 실행 권한을 유지해 푼다: `ditto -x -k Dots-Voice-Mac.zip ~/` → `~/Dots-Voice-Mac`. 데스크탑·문서·다운로드 폴더는 macOS 개인정보 보호 대상이라 Chrome이 실행기를 시작할 때 막힐 수 있으므로 피한다. 설치 후 폴더를 옮기면 다시 설치해야 한다.
- 지원 환경은 Apple Silicon(arm64) macOS, Python 3.11, Google Chrome이다. Intel Mac이면 지원하지 않는다고 알리고 멈춘다. Windows면 `Dots-Voice-Windows11.zip` 패키지가 필요하다고 알린다.

## 지킬 것

- 포함된 `voices/designed-soft.wav`, 모델·revision, `config/voice_settings.json`, 확장 공개 키(`manifest.json`의 `key`)는 기본 설치 시 유지한다. 사용자가 목소리·모델 교체를 요청하면 `docs/VOICE_MODELS.md`에 따라 백업 후 요청한 항목만 변경한다. 확장 공개 키는 유지한다.
- 설치 전에 `python3.11 src/voice_launcher.py --status`로 실행 중인 서버를 확인하고 같은 모델을 여러 번 로딩하지 않는다. 8766 포트를 쓰는 관계없는 프로세스를 종료하지 않는다.
- `chrome://extensions` 같은 Chrome 설정 화면을 자동화하거나 우회해서 조작하지 않는다. 확장 등록·새로고침은 사용자가 한다.
- Gatekeeper, 전체 디스크 접근 같은 보안 설정을 임의로 바꾸지 않는다. `runtime/tts-bridge-config.json`의 인증 토큰을 출력하거나 공유하지 않는다.

## 순서

1. `SETUP.md` 1–2단계: 환경·파일 확인, 설치. 설치는 오래 걸리므로 필요하면 백그라운드로 실행한다.
2. `SETUP.md` 4단계의 모델을 로딩하지 않는 검사를 실행한다.
3. 사용자에게 Chrome 확장 등록을 안내한다. 클릭할 항목, 선택할 폴더의 **절대 경로**, 퍼즐 아이콘에서 Dots Voice를 고정하는 방법을 알려주고 완료했다는 답을 기다린다.
4. 사용자가 dots 대화 탭에서 도구 모음의 Dots Voice 버튼을 누르게 하고 팝업 문구를 묻는다. `로컬 목소리 연결 완료`가 목표다. 팝업이 `확장 프로그램을 새로고침해 주세요`면 팝업 버튼이나 확장 카드의 새로고침을 누르게 한다.
5. 목소리가 들리는지, 원음과 겹치지 않는지, 말하면 멈추는지는 사용자에게 확인을 요청한다. 에이전트가 직접 들었다고 보고하지 않는다.
6. 문제가 생기면 `SETUP.md`의 오류 처리를 따른다.

## 완료 보고

설치 위치, 실제로 실행해 통과한 검사, Chrome 등록 여부, 실제 통화 확인 여부(사용자가 확인했는지 포함), 사용자가 할 다음 동작만 짧게 보고한다. 확인하지 않은 단계를 확인했다고 쓰지 않는다.
