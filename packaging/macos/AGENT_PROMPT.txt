첨부한 Dots Voice 설치 패키지(Dots-Voice-Mac.zip 또는 압축을 푼 폴더)를 내 Mac에 설치하고 Chrome dots 통화에 연결해 줘.

- ZIP이면 먼저 ~/Dots-Voice-Mac 처럼 홈 폴더 아래 계속 둘 위치에 실행 권한이 유지되게 풀어 줘. 데스크탑·문서·다운로드 폴더는 피해 줘.
- 폴더의 AGENTS.md를 먼저 읽고 SETUP.md 순서대로 환경 확인, 설치, 검사를 진행해 줘.
- 포함된 로컬 목소리 WAV, 모델과 revision, 설정, 확장 키는 바꾸지 마.
- Chrome 확장 등록처럼 내가 직접 해야 하는 단계는 무엇을 누르면 되는지 정확히 알려주고, 내가 했다고 하면 이어서 확인해 줘.
- 끝나면 실제로 통과한 것과 내가 아직 확인해야 할 것을 나눠서 짧게 알려줘.
