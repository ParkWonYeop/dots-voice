## 다운로드와 설치

- [Mac · Apple Silicon ZIP](https://github.com/ParkWonYeop/dots-voice/releases/download/v1.2.2/Dots-Voice-Mac.zip)

## 목소리·모델 교체

음색은 참조 WAV와 `referenceAudio`·`referenceSha256`을, 합성 모델은 호환 Base 모델의 `model`·`revision`·`modelDirectory`를 함께 바꿉니다. 백업·재설치·확인 절차는 ZIP에도 포함된 [교체 안내](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.2/docs/VOICE_MODELS.md)를 따르세요.

모델 없는 Python·오디오·JavaScript 검사와 두 설치 ZIP의 라이선스 포함 여부·무결성·실행기 통신을 확인했습니다. Windows 실기기 합성·Chrome 통화는 미검증입니다.
