Dots Voice의 첫 공개 릴리즈입니다. Chrome dots 통화 답변을 포함된 한국어 캐릭터 참조 목소리로 합성하며, 음성 합성은 로컬에서 실행됩니다.

Assets에서 운영체제별 ZIP을 받으세요. 자동 생성되는 `Source code (zip)`은 개발용 소스입니다. 모델은 설치 중 내려받으므로 설치 ZIP에는 포함하지 않습니다.

## 직접 설치

Python 3.11과 Google Chrome을 준비하고 ZIP을 홈 폴더 아래 고정 위치에 풉니다. Mac은 `Dots Voice 설치.command`, Windows는 `install-windows.cmd`를 실행합니다. 설치 후 Chrome의 `chrome://extensions`에서 개발자 모드 → 압축해제된 확장 프로그램 로드 → 설치 폴더의 `runtime/chrome-extension`을 선택합니다.

dots 대화 탭에서 **Dots Voice → 2번 목소리 연결 완료 → 통화 시작** 순서입니다.

[전체 설치 안내](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.0/README.md#방법-1--직접-설치) · [Mac 상세 안내](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.0/packaging/macos/SETUP.md) · [Windows 상세 안내](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.0/packaging/windows/SETUP.md)

## ZIP + 프롬프트로 설치

설치할 컴퓨터에서 실행 중인 Codex·Claude Code·Cursor 등에 ZIP 또는 압축 해제 폴더를 주고, 안에 든 **`AGENT_PROMPT.txt`** 내용을 보냅니다. 에이전트가 `AGENTS.md`·`SETUP.md`에 따라 환경 검사·설치·진단을 진행합니다. Chrome 확장 등록과 실제 청취 확인은 사용자가 직접 합니다.

[Mac 프롬프트](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.0/packaging/macos/AGENT_PROMPT.txt) · [Windows 프롬프트](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.0/packaging/windows/AGENT_PROMPT.txt)

## 변경과 확인 범위

- 서버 자동 시작·재사용, 연결 단계와 상태, 미리듣기, 원래 목소리 복원.
- 고정 참조 음색, 자막 묶음 처리, 사용자 발화 시 합성 취소, 연속 리샘플링·무음 보정.
- 소스·설정·검사·문서·패키징을 분리하고 운영체제별 설치 ZIP 제공.
- Mac에서 Python 24개 단위 검사, 오디오·프로세스 검사, JavaScript 확장·자막 검사 통과. 두 ZIP의 전체 파일 해시·플랫폼 설정·실행기 ping 검증.

**Windows 실기기 설치·합성·Chrome 통화는 미검증**입니다. Windows 설치기가 해당 PC의 CUDA/CPU와 합성 속도를 검사합니다. Windows는 구절 전체 합성 후 재생하므로 Mac 스트리밍과 지연·음색이 다를 수 있고, CPU에서는 응답이 느릴 수 있습니다. Intel Mac·Windows ARM은 지원하지 않습니다. 본인 ChatGPT 계정의 dots 웹 통화 접근 권한이 필요합니다.
