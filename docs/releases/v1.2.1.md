확장 화면·설치 지침·코드의 목소리 명칭을 **로컬 목소리**로 통일했습니다. 실제 기본 음성·모델 설정은 유지합니다.

## 다운로드와 설치

- [Mac · Apple Silicon ZIP](https://github.com/ParkWonYeop/dots-voice/releases/download/v1.2.1/Dots-Voice-Mac.zip)
- [Windows 11 · x64 ZIP](https://github.com/ParkWonYeop/dots-voice/releases/download/v1.2.1/Dots-Voice-Windows11.zip)
- [ZIP SHA-256](https://github.com/ParkWonYeop/dots-voice/releases/download/v1.2.1/SHA256SUMS.txt)

직접 설치는 압축 해제 후 **Mac `install-mac.command`**, Windows `install-windows.cmd`를 실행하세요. 에이전트 설치는 해당 PC의 Codex·Claude Code 등에 ZIP과 내부 `AGENT_PROMPT.txt` 내용을 전달하면 됩니다. [전체 설치 안내](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.1/README.md)

기존 사용자는 새 패키지에서 설치기를 실행한 뒤 Chrome 확장 카드를 새로고침하세요. Mac 설치 파일명이 변경됐습니다. 사용자 설정을 바꾼 적이 있다면 먼저 백업하세요.

## 목소리·모델 교체

[교체 안내](https://github.com/ParkWonYeop/dots-voice/blob/v1.2.1/docs/VOICE_MODELS.md)를 추가했고 두 ZIP에도 포함했습니다.

- 음색만 변경하려면 새 참조 WAV와 `referenceAudio`·`referenceSha256`을 설정합니다.
- 합성 모델은 플랫폼에 맞는 Base 모델의 `model`·`revision`·`modelDirectory`를 함께 바꿉니다.
- 서버를 종료하고 백업한 뒤 수정·설치·미리듣기·통화 확인 순서로 진행합니다. Windows는 `config/voice_settings.windows.json`을 수정해야 재설치 후에도 유지됩니다.
- CustomVoice·VoiceDesign과 다른 TTS 계열의 지원 범위, 문제 확인과 원복 방법도 문서에 정리했습니다.

Python·오디오·JavaScript 검사와 두 설치 ZIP의 무결성·실행기 통신을 확인했습니다. Windows 실기기 합성·Chrome 통화는 여전히 미검증입니다.
